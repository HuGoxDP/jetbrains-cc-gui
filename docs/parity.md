# Паритет функций: Swttch ↔ CC GUI

Этот файл одинаковый в обоих репозиториях:

- `HuGoxDP/Claude-Code-with-GUI` (**Swttch**: Node-бэкенд, React-вебвью, Kotlin-мост) — `docs/parity.md`
- `HuGoxDP/jetbrains-cc-gui` (**CC GUI**: Java, ai-bridge, вебвью) — `docs/parity.md`

Цель: у обоих плагинов одинаковый набор функций. Функции только добавляются, ничего не удаляется.

Список составлен по коду обоих репозиториев (действия IDE, настройки, компоненты, бэкенд). При переносе функции её статус обновляется в обоих файлах сразу.

Статусы: ⬜ не сделано · 🔧 в работе · ✅ сделано · 🚫 не переносится (причина в строке)

## Не переносится

- **Другие ИИ-движки CC GUI** (Codex, Grok, Kimi, OpenCode, PI, OMP, DeepSeek) и **Codex pet** — Swttch по своим правилам работает только с Claude Code CLI.
- **Список Node-процессов CC GUI** — нужен из-за его архитектуры (ai-bridge); в Swttch этой проблемы нет.
- **Открытие файлов во внешнем редакторе (Swttch)** — нужно только в браузерном режиме, которого у CC GUI нет (см. A17).
